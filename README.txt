MY BETTER SELF — FREE STARTER APP

Files:
- index.html: app
- manifest.json: installable web app settings
- sw.js: offline caching
- icon.svg: app icon

HOW TO USE:
1. Extract the ZIP.
2. Host the folder on a free HTTPS static host (GitHub Pages is one option).
3. Open the HTTPS link in Chrome on Android.
4. Chrome menu (three dots) > Add to Home screen / Install app.
5. Open the app and use Settings > Enable notifications.

IMPORTANT:
- Salary plan starts with AED 1,200 salary, AED 700 family remittance, AED 230 food, AED 20 Wi-Fi, AED 0 advance repayment. Edit these if they change.
- Expenses and progress are stored locally in that browser/device. Export your data regularly.
- Basic reminder notifications work only while the app is open and the browser permits them. They are not guaranteed when closed or when the phone restricts background activity.
- No login, cloud sync, or paid service is included.
